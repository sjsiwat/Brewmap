# BrewMap AI — API server

NestJS 11 + MongoDB (Mongoose). Serves café data to the Next.js app in `../web`.

## Setup

```bash
npm install
cp .env.example .env      # paste your MongoDB Atlas connection string into MONGODB_URI
npm run seed              # loads ../web/data/cafes.json into MongoDB (safe to re-run)
npm run start:dev         # http://localhost:4000/api
```

API docs (Swagger): http://localhost:4000/api/docs

### MongoDB Atlas

1. Create a free M0 cluster.
2. Database Access → add a user. Network Access → add your IP.
3. Connect → Drivers → copy the `mongodb+srv://…` string into `.env` and set the
   database name to `brewmap` (`…mongodb.net/brewmap?retryWrites=true&w=majority`).

## Endpoints

| Method | Path | Notes |
|---|---|---|
| GET | `/api/health` | Server and database status |
| GET | `/api/cafes` | Filters: `minPrice` `maxPrice` `drinkType` `parking` `petFriendly` `tag` `area`. Geo: `lat` + `lng` (adds `distanceKm`, default sort nearest), `radiusKm`. `sort=rating\|distance\|reviews\|price`, `page`, `limit` (≤ 50) |
| GET | `/api/cafes/top` | `tag`, `minReviews` (default 50), `limit` — for "Top 10" lists |
| GET | `/api/cafes/filters` | Distinct areas / tags / drink types and price range for filter UIs |
| GET | `/api/cafes/:slug` | One café, 404 if missing |

Example: `/api/cafes?lat=18.7876&lng=98.9933&radiusKm=3&maxPrice=120&parking=true`

## Data model

`cafes` stores `location` as a GeoJSON point (`[lng, lat]`) with a `2dsphere` index;
responses flatten it back to `lat` / `lng` to match `Cafe` in `web/lib/cafes.ts`.
The source of truth for seed data is `web/data/cafes.json`, generated by
`web/scripts/scrape-cafes/build_cafes_full.py`.

## Tests

```bash
npm test          # unit tests
npm run test:e2e  # full API against an in-memory MongoDB (no Atlas needed)
```

Both scripts run Jest with `--experimental-vm-modules` because the MongoDB 7.7
driver loads `os` via dynamic `import()`, which Jest's CommonJS sandbox otherwise
rejects (symptom: `Missing required sub-document 'driver' in the client metadata document`).
